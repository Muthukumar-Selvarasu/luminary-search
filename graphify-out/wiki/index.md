## Runtime path (what to say on stage)

Browser (`web/src/api.ts`) talks **only** to the gateway (`backend/gateway`, port 8787). The gateway proxies to the agent (`backend/agent`, port 8000). The agent holds keys, runs `executeAsk()`, tools, memory, RAG, and the jobs worker. MongoDB Atlas is the single store.
